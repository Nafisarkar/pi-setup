# pi-setup

Reproducible [pi](https://github.com/earendil-works/pi) configuration — settings, agents, skills, extensions, and pinned package versions.

`agent/` is a byte-for-byte mirror of the pi agent directory (`~/.pi/agent`). Restoring is a straight copy, so there is no translation step that can drift.

## Restore

```powershell
git clone git@github.com:Nafisarkar/pi-setup.git
cd pi-setup
./install.ps1
```

The script is idempotent — re-run it any time to reconcile a machine with this repo. Then start pi and run `/login`.

Copy to a non-default location with `./install.ps1 -AgentDir 'D:\pi\agent'` (or set `PI_CODING_AGENT_DIR`).

## What's here

### Config — `agent/`

| File | Purpose |
| --- | --- |
| `settings.json` | Provider/model defaults, `cc-dark` theme, fullscreen TUI, declared package list |
| `subagents.json` | Subagent runtime: 10 concurrent, background-by-default, worktree isolation |
| `pi-cc-extensions.json` | Footer, diff, and animation behaviour for `pi-cc-extensions` |
| `keybindings.json` | `ctrl+d`/`alt+x` exit, `alt+k`/`alt+j` line scroll |
| `commandcode-models.json` | Model catalog for the CommandCode provider |

### Agents — `agent/agents/`

Tuned for `mimo-v2.6-flash`.

| Agent | Role |
| --- | --- |
| `general-purpose` | Catch-all worker for open-ended, multi-step tasks |
| `Explore` | Read-only search across a codebase |
| `Plan` | Software architect; produces an implementation plan |
| `researcher` | Web research and synthesis |
| `mermaid-maker` | Authors, renders, and visually verifies Mermaid diagrams |
| `svg-maker` | Authors, renders, and visually verifies hand-written SVG |

### Skills — `agent/skills/`

| Skill | Role |
| --- | --- |
| `teach` | Teaching loop built on two verified principles, not rote memorization |
| `visualize` | Adds a diagram to a lesson when the idea is clearer as a picture |

### Extensions — `agent/extensions/`

| Extension | What it does |
| --- | --- |
| `ask-user-question.ts` | Single-question multiple-choice prompt with custom "Other" text entry |
| `quiz.ts` | Graded question tool — marks right/wrong, reveals the answer, explains |
| `md-log.ts` | Mirrors a session to a `.md` file for reading in Obsidian (math and code render natively) |
| `dictate/` | Voice dictation, `alt+m` to start/stop, `alt+n` to cancel. Needs `DEEPGRAM_API_KEY` |
| `ntlite/` | Exposes NTLite (WIM/ESD mounting, image customisation, ISO building) as native pi tools |
| `visual-tools/` | Registers `write_mermaid` / `render_mermaid` / `write_svg` / `render_svg` for the maker agents |

## Not versioned

Deliberately excluded — regenerable, machine-specific, or secret.

| Path | Why |
| --- | --- |
| `agent/auth.json` | Credentials. Written empty on install; populate with `/login` |
| `agent/trust.json` | Contains your home path. Generated by `install.ps1` |
| `agent/models-store.json` | Runtime cache, currently `{}` |
| `agent/sessions/`, `cache/`, `fff/`, `web-search-cache/` | Runtime state, not setup |
| `agent/bin/` | Downloaded binaries (pandoc, ripgrep, fd, sox) — ~250 MB |
| `**/node_modules/` | Restored by `bun install --frozen-lockfile` from the committed lockfiles |

Lockfiles **are** committed, so package installs are exact rather than approximate.

## Environment variables

| Variable | Effect |
| --- | --- |
| `DEEPGRAM_API_KEY` | Enables the `dictate` extension |
| `DICTATE_DEBUG` | Verbose dictation logging |
| `DICTATE_REC=1` | Record while the hotkey is held, instead of press-to-toggle |
| `PI_CODING_AGENT_DIR` | Relocate the agent directory |

Set the first three as user environment variables, or put them in your shell profile.
